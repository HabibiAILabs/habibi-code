Your terminal.

A small coding agent that owns its loop, speaks directly to models, and keeps you in control of every tool.

v0.1.0 · experimental
Install with one command
curl -fsSL https://habibiailabs.github.io/habibi-code/install.sh | sh

Installs to ~/.local/bin. No sudo. SHA-256 verified. Read the installer first or download an archive.

Less machinery. More agency.

Native all the way

A Rust binary and an embeddable engine. No Node.js runtime, daemon, or provider-agent subprocess.

A conversation, not a log dump

Compact tool summaries, styled responses, scrollback, multiline input, and configurable status elements.

Stay in the loop

Steer an active run, queue follow-ups, interrupt with Esc, and resume your saved session later.

Your permission policy

Approve each tool by default. Explicit YOLO mode is available for trusted work—approval is not a sandbox.

Start a session

habibi login codex
habibi --provider codex

# Experimental Claude subscription adapter
habibi login claude
habibi --provider claude

# Pick up where you left off
habibi --resume /path/to/session.jsonl

Open the login URL in your browser. For SSH, paste the failed callback URL into the private login prompt—not chat. Account access and model availability are controlled by the provider.

Pick your machine

PlatformBuilds

Run the installer again to upgrade. A background release check shows a minimal notice when a newer stable version is available; nothing is installed automatically. Set HABIBI_NO_UPDATE_CHECK=1 to disable it.

An honest first release

Subscription adapters are experimental, not verified provider-approved integrations. Real-account authentication and inference have not yet been verified for this prototype. Claude compatibility uses Claude Code-specific identity. Review provider terms. There is no automatic API-billing fallback.

Shell commands run with your account’s access. Saved credentials and sessions are plaintext and may contain sensitive data. Only approve operations you trust.
