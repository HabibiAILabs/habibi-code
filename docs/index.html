Why another coding agent?

Built for a crowded terminal.

Habibi was inspired by Pi: a small agent, a clear loop, and room to make it your own. The motivation for a native implementation was personal.

This is a design goal, not a claim that we've benchmarked 50 concurrent agents. Model servers, MCP processes, active context, and tool workloads have their own costs.

“I liked Pi. I just couldn't run 50 of them on a single machine.”

— The motivation behind Habibi

Keep the spirit. Make the local footprint smaller.
